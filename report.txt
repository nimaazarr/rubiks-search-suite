================================================================================
HEURISTIC ANALYSIS
================================================================================

Heuristic Function: Face Mismatch Heuristic
--------------------------------------------------------------------------------
Description: Counts the number of face colors that don't match the
target uniform color for each of the 6 external faces, divided by
an optimistic factor (max affected cubies per move).

Admissibility: This heuristic is admissible because:
  1. Each move can affect at most 2 * max(dimensions) cubies
  2. We divide the total mismatches by this maximum
  3. This ensures we never overestimate the cost to goal

Consistency: For any state n and successor n':
  h(n) <= cost(n,n') + h(n')
  Since cost(n,n') = 1 for all moves, and each move can reduce
  mismatches by at most a bounded amount, the heuristic is consistent.


================================================================================
ALGORITHM COMPARISON
================================================================================

Blind Search Algorithms:
--------------------------------------------------------------------------------
BFS: Complete and optimal, but explores many states
DFS: Incomplete (with depth limit), may find suboptimal solutions
UCS: Complete and optimal, equivalent to BFS with unit costs
DLS: Complete up to depth limit, not optimal
IDS: Complete and optimal, combines benefits of BFS and DFS

Informed Search Algorithms:
--------------------------------------------------------------------------------
GBFS: Not complete or optimal, but can be fast with good heuristic
A*: Complete and optimal with admissible heuristic
Weighted A*: Trades optimality for speed (W > 1)
IDA*: Complete and optimal, memory efficient
RBFS: Complete and optimal, memory efficient with bounded space


Conclusion:
--------------------------------------------------------------------------------
For this puzzle, informed search algorithms (A*, IDA*, RBFS) typically
outperform blind search by using the heuristic to guide exploration.
A* is usually fastest but uses more memory, while IDA* and RBFS trade
time for space efficiency.

# rubiks-search-suite
A full implementation of blind and informed search algorithms on a generalized 3D Rubik’s cube (x×y×z, 1–4). The project includes BFS, DFS, UCS, DLS, IDS, Greedy, A*, Weighted A*, IDA*, and RBFS, with a custom row-reversal movement model, heuristic design, and complete state-expansion logs for every algorithm.
